# Parcel Pricer

A lightweight, un-opinionated Python library for calculating shipping costs based on parcel dimensions, weight surcharges, and algorithmic bulk discounts.

## Installation

Install the library dependencies via pip:
```bash
pip install -r requirements.txt
```

## Running the Tests

To ensure the calculation engine is running accurately, run the comprehensive test suite utilizing pytest:
```bash
pytest
```

## Usage Example

The library exposes two simple dataclasses and a single calculation function. 

```python
from parcel_pricer import Parcel, calculate_order

# 1. Define your incoming parcels
parcels = [
    Parcel(width=5.0, height=5.0, depth=5.0, weight_kg=1.0),      # Small parcel ($3)
    Parcel(width=10.0, height=20.0, depth=10.0, weight_kg=2.0),   # Medium parcel ($8)
    Parcel(width=100.0, height=100.0, depth=100.0, weight_kg=13.0) # XL parcel with overweight surcharge
]

# 2. Calculate Standard Shipping
standard_result = calculate_order(parcels)
print(f"Standard Total: ${standard_result.total_cost}")

# 3. Calculate with Speedy Shipping
speedy_result = calculate_order(parcels, speedy_shipping=True)
print(f"Speedy Total: ${speedy_result.total_cost}")
```

## Output Structure

The output generated by `calculate_order` is structured via native Python Dataclasses to make iteration and invoice generation simple:

- `OrderResult`: The root response object.
  - `total_cost` (float): The final mathematically computed cost of the entire order after all operations (base sizes, weight surcharges, optimal discounts, and speedy shipping multipliers) have been applied.
  - `items` (List[`ParcelResult`]): A chronological list of line items representing the invoice.
    - Each `ParcelResult` contains a `parcel_type` (e.g., `"Small"`, `"Heavy"`, `"Medium Mania Discount"`) and its associated `cost` (which may be negative in the case of a discount).
